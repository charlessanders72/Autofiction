# Autofiction System Report

How the protocol, GitHub workflows, and daily story generation fit together.

---

## Overview

Autofiction is a self-improving fiction engine. It pairs prompts from the [Daily Micro Fiction](https://www.dailymicrofiction.com/p/index) index with current news headlines and feeds them through a five-step protocol that ends with the protocol rewriting itself. Since February 9, 2026, the system has produced 13 stories across five days and accumulated 22 merged pull requests on the `Main-Branch` default branch.

---

## The Five-Step Protocol (`PROTOCOL.md`)

Every story, whether generated manually or by CI, follows the same loop:

| Step | Action | Output |
|------|--------|--------|
| **1. Pick an Idea** | Match a Daily Micro Fiction letter (day of month) with a CNN headline. Identify the human tension. | A concept sentence. |
| **2. Create an Outline** | Define a theme (universal thesis + conflict + arc), character(s) with backstory, setting, and a 2-4 scene plot. | A structured outline. |
| **3. Generate the Story** | Send the outline to Claude Opus with a detailed prompt specifying length (500-1,000 words), no em dashes, show-don't-tell, abrupt ending, and several craft rules that have been added by the recursive loop. | A finished short story. |
| **4. Log and Commit** | Save to `stories/YYYY-MM-DD-slug.md` with metadata and outline. Commit to a feature branch. Update the daily memory log. | A committed story file + memory entry. |
| **5. Recursive Analysis** | Analyze the story for craft strengths/weaknesses. Make at most one sentence-level change to `PROTOCOL.md`. Log the change. | A (potentially) improved protocol for the next story. |

The recursive loop is the key design idea: each story generation cycle sharpens the instructions for the next one. Over 13 stories, the protocol has gained several craft rules through this process:

- "If you find yourself explaining what a character understands or realizes, cut the explanation and trust the reader to infer it from what the character does next." (added after "The Architecture," Feb 13)
- "When interior reflection or backstory is necessary, anchor it with physical detail or action to maintain pacing." (added after "The Shape It Takes," Feb 11)
- "Open with the conflict already in motion; establish atmosphere through the action, not before it." (added after "The Measure," Feb 11)

## GitHub Actions Workflow (`.github/workflows/autofiction.yml`)

### Trigger

The workflow fires in two ways:

1. **Daily cron** -- `0 13 * * *` (1 PM UTC / 8 AM Eastern), every day.
2. **Manual dispatch** -- the `workflow_dispatch` event, triggerable from the GitHub Actions UI.

### Job: `generate-story`

Runs on `ubuntu-latest` with a 10-minute timeout. Four steps:

#### 1. Checkout

```yaml
- uses: actions/checkout@v4
  with:
    ref: Main-Branch
    fetch-depth: 0
```

Checks out the full history of `Main-Branch` so the protocol, memory, and all prior stories are available.

#### 2. Install Claude Code

```yaml
- name: Install Claude Code
  run: npm install -g @anthropic-ai/claude-code
```

Installs the Anthropic CLI globally in the runner.

#### 3. Run the Protocol

```yaml
- name: Run autofiction protocol
  env:
    ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
  run: |
    claude --print "run autofiction protocol" \
      --allowedTools "Read,Write,Edit,Glob,Grep,WebFetch,WebSearch,Bash(git *)"
```

This is the core step. `claude --print` runs Claude Code in non-interactive (headless) mode. The prompt `"run autofiction protocol"` tells Claude to read `PROTOCOL.md` and execute all five steps. The `--allowedTools` flag restricts tool access to file operations, search, and git commands only (no arbitrary shell execution).

Claude reads `PROTOCOL.md`, picks a Daily Micro Fiction topic, searches for a CNN headline via `WebSearch`, generates the outline and story, writes the file to `stories/`, updates the daily memory log, performs recursive analysis, and optionally modifies `PROTOCOL.md`.

#### 4. Push and Open PR

```yaml
- name: Push and open PR
  run: |
    git config user.name "github-actions[bot]"
    git config user.email "github-actions[bot]@users.noreply.github.com"

    branch="autofiction/$(date -u +%Y-%m-%d-%H%M)"
    git checkout -b "$branch"

    git add stories/ memory/
    git diff --cached --quiet && echo "No changes to commit" && exit 0

    story=$(git diff --cached --name-only -- stories/ | head -1 | xargs basename | sed 's/\.md$//')
    git commit -m "Add story: ${story}"
    git push origin "$branch"

    gh pr create \
      --title "Story: ${story}" \
      --body "Automatically generated by the Autofiction protocol (daily)." \
      --base Main-Branch
  env:
    GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

After Claude finishes:

- Creates a timestamped branch (`autofiction/YYYY-MM-DD-HHMM`).
- Stages only `stories/` and `memory/` directories.
- Exits cleanly if there are no changes.
- Extracts the story slug from the filename for the commit message.
- Pushes the branch and opens a PR to `Main-Branch` using `gh pr create`.

### Secrets Required

| Secret | Purpose |
|--------|---------|
| `ANTHROPIC_API_KEY` | Authenticates Claude Code against the Anthropic API |
| `GITHUB_TOKEN` | Provided automatically by GitHub Actions; used by `gh pr create` |

### Permissions

The workflow requests `contents: write` and `pull-requests: write` at the job level, which allows it to push branches and create PRs.

## Memory System

A two-layer system persists context across sessions:

| Layer | File | Lifecycle |
|-------|------|-----------|
| **Long-term** | `MEMORY.md` | Curated, persistent. Key decisions, conventions, lessons learned. |
| **Daily logs** | `memory/YYYY-MM-DD.md` | Append-only. One per day. Running session notes, tasks, learnings. |

There are daily logs for Feb 7, 9, 10, 11, 12, and 13. New logs are created from `memory/TEMPLATE.md`. Durable facts get promoted from daily logs into `MEMORY.md` over time.

The automated workflow stages `memory/` alongside `stories/`, so daily logs created during CI runs are included in the PR.

## How the Pieces Connect

```
Daily Micro Fiction Index ──┐
                            ├──▶ Step 1: Pick an Idea
CNN Headlines (via WebSearch)┘
                                    │
                                    ▼
                            Step 2: Create an Outline
                                    │
                                    ▼
                            Step 3: Claude Opus generates the story
                                    │
                                    ▼
                            Step 4: Save to stories/, update memory/
                                    │
                                    ▼
                            Step 5: Recursive Analysis
                                    │
                               ┌────┴────┐
                               │         │
                    (optional edit    Log strengths/
                     to PROTOCOL.md)  weaknesses in
                               │      story metadata
                               │         │
                               └────┬────┘
                                    │
                                    ▼
                    GitHub Actions: commit, push branch, open PR
                                    │
                                    ▼
                    Human review ──▶ Merge to Main-Branch
                                    │
                                    ▼
                    Next run picks up the improved PROTOCOL.md
                              (loop repeats)
```

The system is a feedback loop: each story teaches the protocol something, the protocol gets a one-sentence edit, and the next story benefits from the accumulated craft wisdom. The GitHub Actions workflow automates the daily trigger, while the PR-based merge flow keeps a human in the loop for quality review.
